# 展示环境任务页只读浏览

2026-10-28，已实施。目标：展示环境进入「目标与数据」时可浏览已有任务与进度，不因页面或折叠区域初始化本地存储。

- 空工作区直接进入或从历史页进入时，不创建目录、数据库或其他文件；提供示例与历史入口。本地工作台仍可正常创建任务。
- 已有任务、分析预览、数据版本与相关记录继续可读；侧栏漏斗、任务规约及相关服务使用只读连接，缺少可选存储按空列表处理，损坏存储明确报错，不修复或冒充没有任务。
- 变更任务、运行训练、评测或进程控制等执行入口在展示模式仍不可用；SQLite 使用 mode=ro，服务写入口在处理输入或外部请求之前拒绝只读调用。
- SQLite 的 WAL 模式或残留 WAL/SHM 文件可能令只读连接写共享文件，不能通过忽略 WAL 的方式返回过时数据。展示环境明确提示使用本地工作台，不自动修改、删除或 checkpoint；此检查针对稳定的存储状态，不声称能原子阻止其他进程并发切换日志模式。
- 验收：空工作区、现有任务、分析预览、已物化数据、损坏记录与数据库、禁用按钮伪点击、WAL 未 checkpoint 数据，验证完整目录/文件字节无变化；本地创建、训练/评测相关既有回归继续通过。
