# 示例与历史工作区

日期：2026-10-28。状态：已实现并验证。依据：用户要求继续美化前端，补足事例数据、历史数据和展示感。

示例卡片在预览展开后标出当前选择并提供数据区锚点；卡片、数据选择器与跨页面返回共享选择。交接历史对照保留原始报告状态，存在截断或处理失败时按模型和题目汇总说明，失败记录仍留在评分分母中。

公开交付档案的数据版本或名称缺失、不是非空文本，或训练结束时间缺失、不是可解析的日期时间时，明确显示不可核验并保留可核验的权重与评测；不推断缺失时间或时区。

## 目的

首次打开 TuneSmith 即能看到真实的数据形态、训练过程、同题输出和交付产物；本地已有任务继续可达。沿用当前深蓝与紫色视觉，不另建展示站点。

## 数据与交互

- 首页直接展示分类、抽取、开放生成三张示例卡，包含目标、实际数据预览、记录量、原型及下一步。数据来自现有虚构 CSV；可查看和下载。本地用户可用原始示例创建任务；创建不跳过核验；展示环境只读。
- 首页提供公开历史验证成果：实际 R149 64 更新训练、64 点 loss、四模型同题结果与交付格式。所有数值从仓库证据读取；不伪造多轮改进、运行中活动或时间。展示原基座 8 条截断，报告仍为 completed_with_failures。
- 历史档案提供训练配置/曲线、开发题原始输入与标准答案、四模型完整原始输出及状态、实际成本、HF/GGUF 文件信息及证据下载。开发题只有两个 ticket 组，保留未完成真实业务验收的说明。
- 实验页、评测页和模型对照页提供公开历史与本地记录的明确切换/入口。公开档案无需 MLflow、模型、GPU、API key 或种子脚本，进入不写任务或实验存储；本地记录失败不能冒充暂无数据。
- 切换记录/样例会更新详情；查看历史不运行训练或推理、不泄露最终测试逐行数据、不修改原始证据。

## 视觉与可用性

- 首页首屏含具体样例与成果，采用留白、分层卡片、紧凑标签与可阅读图表；避免整页警告或密集参数表。
- 使用原生 Streamlit 交互，按钮/选择器可键盘操作，标题层级清晰。所有动态 HTML 文本转义。窄屏卡片与指标换行，不产生横向页面溢出；图表自适应。
- 读取缺失/损坏证据时明确说明，并保留本地任务入口，不编造备用指标。

## R151 浏览体验增量（2026-10-28，已实现并验证）

- 同题对照增加八题总览，保留 ticket 分组、期望答案和四模型结果；点选行能定位原始输出，原有题目下拉仍可使用。
- 支持全部模型与两模型对照。两模型模式可选择左右模型，筛选原始文本或生成 token 不同、未通过或截断的题；筛选针对当前模型对，显示保留题数/固定总题数。
- HF 对 GGUF 的全部文本和 token 一致时明确显示一致；差异筛选为空是正常结果，可返回全部题目。未记录的 token 证据不冒充一致。
- 训练曲线明确关联最终更新后的输出，不能把中间 loss 点当作每步业务评测。
- 本地实验的详情、对比、曲线和删除均按 run_id 选择；同名运行分别可选，缺名显示可辨识回退，筛选后无结果有明确空态。
- 验证当前对照切换/筛选与题目定位、同名运行选择/对比/曲线的正确身份，并保持只读档案不写入。

## R154 本地别名操作（2026-10-28，已实现并验证）

- 设置与移除分别显示当前绑定、目标和模型名称；移除不受设置目标版本影响，保留所有版本和权重。相同绑定与未绑定移除不提交请求。
- 点击前读取当前绑定；与页面显示不同则不提交并刷新，让用户核对。此检查不是原子并发锁。
- 写入后重新读取确认结果；成功回执在控件触发的重跑后保留。读取/写入失败与未确认结果分别说明，不把无操作或未知结果显示为成功。提供只读刷新按钮，展示环境仍拒绝任何伪点击写入。
- 验收：真实临时 MLflow 注册表验证设置、移除、旧绑定冲突与错误结果；AppTest 验证目标/当前绑定、刷新后的回执和展示环境禁写。

MLflow SQLite 实证：`search_model_versions` 返回的版本别名为空，但注册模型的绑定为 champion→2；版本表改从注册模型读取真实绑定，按模型名称和版本关联；读取失败仍报错，不显示为未绑定。别名写入使用指定 URI 的客户端，不创建训练实验；回调固定用户点击前看到的模型、别名和绑定，避免重跑先更新画面后丢失旧操作身份。
