# 训练与评测记录的缺损隔离

2026-10-28。任务页在训练存储含有损坏记录时仍展示可核验的本任务记录；无法读取或归属不明的条目明确计数，不把它们归为当前任务或默认为不存在。训练服务严格列举接口不改变，页面使用通过身份、状态与必要结构检查的已读取快照，恢复父子关联按任务和运行身份核验。训练状态与产物的既有校验继续生效，跨文件并发变更不保证原子快照。

领域评测与模型对照按新到旧读取结果文件；JSON 顶层与嵌套结构异常时提示损坏文件名并跳过，若回退则标明正在使用的较早文件。所有文件不可读时不声称没有记录；合法空列表仍代表该次结果为空，不回退到更早数据。允许缺失指标或未知值，重复模型名称的筛选状态相互独立。

训练 loss 文件缺失和损坏分开处理；损坏行不阻止有效点显示，但不能据残缺曲线判断完整趋势。起止时间缺失、时区无法比较或顺序矛盾时，耗时与成本保持未知。评测指标中的布尔值、非有限数或计算溢出不得变成虚构差值。
