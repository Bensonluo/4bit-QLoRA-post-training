# 数据与执行证据一致性

2026-10-28。JSONL 按物理换行符分隔记录；合法字符串内的 Unicode 行分隔字符仍属于原始文本，并保留准确行号和空行提示。

自动迭代在训练准备与启动前重新读取绑定的当前任务，校验最新盲标核验状态；待答、失效或相互矛盾的状态不得使用旧的通过结论。检查与跨进程启动之间不提供原子保证。

公开历史卡片对生成失败、截断等证据如实披露，不把失败当作完整输出。回声检测按原规则识别至少 12 个连续相同字符，在长提示和输出上避免二次复杂度；不得截断输入或改变判断结果。

单来源全量资料复用前须核对原始文件与已确认摘要；重复上传若同摘要存档内容损坏，拒绝覆盖并保留当前会话。组合来源继续使用数据库中已解析的来源视图。

待补答案清单中的行 ID 是当前预览编号。原始记录可核验时，清单提供来源文件、工作表和记录起始行；组合来源通过原始摘要、别名、来源视图和行 ID 唯一核验后列出关联位置，并提示核对答案字段归属。存在歧义、来源或预览不匹配时不猜测位置。填写后的清单是交接物，需手动回填原文件，不可直接上传自动回填。

人工填写的待补答案清单提供 XLSX，内容均以文本单元格写入，不把以公式字符开头的原始数据当作公式。对 Excel 无法容纳的超长内容或非法字符不截断，明确提示；原始 CSV 仍供程序读取，并提示直接用表格软件打开时可能识别为公式。

Excel 中的错误单元格或无法表示的非有限数值在读入时阻断，并指出工作表和单元格位置；普通空值、未缓存公式和字面错误文本仍按原有语义处理。

预测标签的收益率先精确计算价格差，再以 28 位有效数字、ROUND_HALF_EVEN 计算；精度或指数超出计算范围时阻断并保留空标签。历史数据版本不被重写，重新生成的收益率和摘要可能变化。
