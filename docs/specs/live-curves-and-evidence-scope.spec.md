# 实时曲线与证据范围

2026-10-28。训练中的 loss 曲线使用框架回调传入的全局步数；刷新时只能读到完整版本的曲线文件，实时呈现写入失败不得中断训练。训练完成后的权威记录仍由完整 log_history 生成。

领域评测回退到 MLflow 时，只使用明确属于当前领域的记录；旧记录缺少领域标签时，不推断归属。导入原始评测文件与医疗评测记录时写入领域标签。

数据分区中排除的记录不能计入实际纳入的重复例题，重复记录在训练集和评测分区的影响须分别说明。学习率分档只按已知的实际训练集条数给出，缺少条数时不猜测。历史案例和交付详情的分组范围以已核验计数为准，无法核验时不推算也不展示确定的分组信息。
