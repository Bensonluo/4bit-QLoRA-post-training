# 训练与证据绑定

2026-10-28。盲标核验绑定实际解析后的来源视图、完整转换预览及方案，不能仅凭原文件哈希推断不同工作表或解析选项具有相同数据。视图不一致的历史核验不授权当前训练；已发起而失效的核验要如实提示。独立题目的既有暴露记录仍须保留。

绑定任务存储的训练在耗时预检后、进程交接前再次读取最新任务与盲标核验。自动技术重试使用经摘要验证并固定的父运行存储绑定，子运行启动前同样复查；跨存储检查与进程启动之间不保证原子性。

样例对比核验须绑定解析后的来源视图与完整预览；切换同一文件的工作表不得沿用旧核验，旧式仅绑定原文件摘要的记录不自动授权。训练成功回执须核验 adapter 配置、权重和 tokenizer 配置的清单、路径及内容；产物不一致时以产物异常呈现，兼容没有 loss 历史的旧清单。

训练成功回执中的基础模型身份与产物清单必须一致；当指标在回执或清单中存在时，必须与已核验的指标文件及其路径一致。旧记录双方均未记录身份或指标时保留既有兼容行为。

盲标核验的离线题目清单在独立作答模式下不得包含现有答案；逐条审阅模式必须提供待审答复与空白的“是/否”结论栏。原始 CSV 的电子表格公式风险须明确提示。

普通 HF 评测结束后复核基座和 adapter 的文件身份；若发生变化或不可读，保留已生成原文及截断状态，但不将结果记为有效评分，固定分母不变。释放失败仍阻止后续模型加载。复核需再次读取模型文件，跨文件读取和检查之间不是原子快照。

训练 worker 在预检之前核对任务快照与已确认的任务 ID、版本和完整数据集元数据，预检的数据必须与训练交接一致。核验针对稳定文件；不保证跨文件并发更改的原子性。

最终验收读取数据库时核对行身份和版本与快照一致，并在占用留出题之前再次核对记录和预检时冻结内容。损坏或错绑的记录不能执行或占用留出题。

领域评测样本仅将布尔 false 计为错误；未知状态单独展示并保留原始状态。输入和模型输出按文本展示，筛选结果未全部显示时说明范围。
