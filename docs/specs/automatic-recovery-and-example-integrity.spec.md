# 自动恢复与内置示例的证据约束

2026-10-28。获准自动技术重试的训练应绑定调用方显式提供的任务存储，并在恢复前重读当前任务及盲标结论。待核验、失效、变更、缺少来源或来源绑定不一致时阻止重试并说明；不得从运行快照或目录位置猜测当前状态。普通不启用自动恢复的训练保持原行为。来源路径仅保存在私有 sidecar；运行记录只保留绑定摘要，持有启动互斥标记者写入。条件变化时持久记录阻止或取消状态，不覆盖已有恢复声明或子运行。当前检查与实际启动不是跨存储原子事务；展示只读连接遇 SQLite WAL 时拒绝读取，相应自动恢复也将提示不可用。

内置示例的所有创建入口共用样例 CSV 校验：不允许重复或空表头、缺列、行列数不符、空输入或空答案；原始字节不改，单份异常不影响其他示例。此规则只作用于内置示例，不限制用户提供的未标注数据。

公开历史的巨大或非有限数值不能导致页面崩溃或构成有效证据；不可核验档案应独立隔离，健康档案继续可读。
