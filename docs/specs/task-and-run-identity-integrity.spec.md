# 任务和训练记录身份一致性

2026-10-28。读取任务时，SQLite 行的任务 ID 和 revision 必须与解码后的快照一致；严格接口拒绝错配，容错列表单独计数，健康任务可继续浏览。历史 revision 也核对其行身份和版本，避免把别的任务或版本误当作当前证据。

训练进程退出后须重新检查最终回执，只有确认没有有效终态回执时才报告缺失；回执不能覆盖或凭空注入准备阶段的任务、数据、模型、配置和恢复授权身份。状态、产物和指标等真实结果仍按原流程核验，停止请求不能掩盖已保存的真实终态。

公开训练研究的基座/训练臂角色由实际记录上下文确定，不从精度字段是否存在推断。缺失精度显示未知，保留真实训练曲线；无效精度数据不能作为可信详情展示。
