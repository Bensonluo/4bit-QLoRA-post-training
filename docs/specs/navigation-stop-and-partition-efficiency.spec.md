# 历史导航、停止与分区读取

2026-10-28。实验页取消所有已选状态或实验时显示无匹配记录，重新选择后恢复；模型未选择仍表示不限制。历史卡片应明确标识当前选择并提供定位对应详情的入口，卡片与详情选择器保持一致。

自动迭代的停止请求必须阻止尚未交接的训练，并保留已准备运行的身份；停止与最终启动交接协调，缓慢预检不能持有该交接锁。评测调用正在执行时，提示当前调用结束后不再继续；返回后的停止检查与报告绑定不提供跨存储原子保证。不能虚报训练已启动或已停止。

每次数据预检、开发集比较或诊断使用同一次完整校验的分区包；三个分区均检查不可变版本及文件哈希，固定题集仍核对题目和来源。只读检查遇到缺失存储不创建目录；跨文件并发变化不构成原子快照。
