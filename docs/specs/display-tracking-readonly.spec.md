# 展示环境的实验与模型库只读浏览

2026-10-28，已实施。展示环境浏览任务总览、实验、领域评测与模型版本时，不因读取而初始化 MLflow 存储。

- 对现有本地文件型实验库，只在存储目录及 MLflow 所需的 `.trash` 已存在时读取；模型库还须确认实际注册库的 `models` 目录。不存在的空库不自动初始化；已有但不完整、不可访问或不支持安全读取的库要显示未知或不可读，不能声称没有数据。
- 展示环境不打开 SQLite 和远程 MLflow 存储：即使只查询，客户端也可能初始化数据库、迁移或 checkpoint WAL。训练任务里的 SQLite 注册状态也不查询，提示在本地工作台查看。公开历史仍可浏览，本地模式保持原有行为。
- MLflow 的实验库和注册库可分别配置；模型页必须检查实际使用的两个地址，不能仅检查实验库。
- 此检查针对稳定存储状态；另一个进程在检查后并发更换或删除目录时，不能保证原子性。展示模式的按钮和服务写入守卫仍独立生效。
- 对公开历史的失败题，未生成输出时可保留未知 token 数；缺少必要字段或矛盾记录不可伪造为有效证据。交付和同题对照展示失败状态与固定分母。
