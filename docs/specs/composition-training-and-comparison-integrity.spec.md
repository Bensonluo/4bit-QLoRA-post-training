# 组合来源、训练交接与比较证据

2026-10-28。组合来源以文件内容和实际解析视图共同识别；同一文件切换工作表或解析参数后，旧全量视图不能自动复用。新生成的组合血缘须区分来源别名与实际视图；历史血缘无法唯一对应时不猜测原始记录。

训练启动和 worker 均核验运行身份与实际配置的数据、模型、分区及输出目录，发生错绑时不启动训练或覆盖其他运行。多文件并发修改不具有原子保证。

训练曲线存在无效点、重复或倒退步数时，页面和命令行均保留有效点但不推断整体走势；图表以独立点呈现不完整记录。训练中的临时指标不得触发完整趋势或重复图表。

历史同题对照区分确认一致、确认不同和证据不足，并允许筛选无法比较的题目。缺失生成证据不自动判为相同或不同。
