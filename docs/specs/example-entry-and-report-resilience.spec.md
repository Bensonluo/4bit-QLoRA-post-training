# 示例入口与评测记录可读性

2026-10-28。从历史档案或展示空态进入示例数据时，首页须展开真实 CSV 预览，并保留用户此前选择；浏览不创建任务，不可用的示例仍按现有规则隔离。

模型对照页的附加领域摘要读取失败时提示不可读，不阻断健康评测指标；摘要缺失与文件损坏分别说明。

Excel 工作表选择先匹配用户输入的完整原始名称；不存在精确名称时兼容去空格及序号输入。新建、补充、全量上传和组合 CLI 不得提前去掉合法名称中的空格。

业务评测报告须具备可展示的时间、状态、题目数量、评分规则、模型名称、错误列表及原始题目来源。尚在运行的记录允许尚无模型结果，完成状态不能缺少实际模型，也不能把失败、截断或模型释放失败伪称无失败完成。单条损坏记录被隔离，健康报告仍可读取；旧记录将套件引用记为 null 时筛选不崩溃。

请求最近训练日志时从尾部按块读取，保留原有换行、编码及行数语义；单条超长行仍需完整读取。并发读写不保证跨进程原子快照。
