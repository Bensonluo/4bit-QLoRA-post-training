# 虚构财报流程样例

用于验证 TuneSmith 能否从目标与样例进入数据诊断、方案预览和训练准备。全部公司、财报、价格和交易日历均为虚构，不验证股价预测效果，无需外部数据服务。

在“目标与数据”页面描述目标并上传：

- `filings.csv`：9 条虚构披露，作为主文件。
- `prices.csv`：虚构价格，资料别名 `prices`。
- `calendar.csv`：明确的模拟收盘日历，资料别名 `calendar`。每两天一个收盘时点，刻意不表示真实美股交易日。
- `scenario.txt`：该模拟业务的完整说明，包括价格口径、观察期与时间边界，可复制到任务说明。

让已配置的 Agent 分析与实际预览后核对结果。已有工作台会话名为“虚构试点：财报目标＋样例数据 → Agent分析与处理方案”，本次本地工作区已用实际 GLM 生成方案并完成数据处理与训练准备检查；记录见 `docs/validation/synthetic-agent-intake-2026-09-27.json`。未进行新训练或预测效果验证。

固定配方的本地通路已验证：训练、开发、测试各 2 条；2 条标签窗口跨界、1 条标签未成熟，都保留明确原因。该结果不等于 Agent 已正确理解任务。

两份异常资料可替换对应来源，检验诊断是否具体：`filings_missing_timestamp.csv` 缺少首条披露时间，`prices_missing_session.csv` 缺少窗口中的一条行情。程序应指出问题，不能猜时间、跳过缺失交易日或补造标签。
